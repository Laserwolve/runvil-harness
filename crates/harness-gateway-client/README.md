# Harness gateway client

This crate is the standard way a Host connects the Harness to the Runvil gateway. It supplies the inference broker that runs each model round through the gateway, which can stream a reply to the Host as it forms, and the search provider that runs web searches through the gateway. Its `provide_gateway_resources` offers the gateway to the Plugins a Host loads through the C contract: every tool call of such a Plugin is lent the address and the key of the gateway's web search, and the Plugin sends its searches there itself. Its wire code opens no connections and reads no clocks, so another broker can reuse it, and credentials never appear in logs or error text.
